## 작업 절차 (매번)

1. 수정 → `node -e "require('./cartlaunch/core.js')"` 로 문법 확인.
2. 브라우저 테스트(아래) → 커밋 → `git push -u origin ccr-16eb7d18-ghxjxq`.
3. 게시: Artifact 도구 `publish`, `file_path: cartlaunch/index.html`, `url`: 위 주소, `files: {"core.js": "cartlaunch/core.js"}`.
   - `capabilities`는 **넘기지 않는다**(이미 `db`, `user`가 선언돼 있고 생략하면 유지됨). `{}`를 넘기면 계정 저장이 꺼진다.
   - `edits`와 `files`는 같이 못 쓴다. 파일을 먼저 고치고 게시한다.
4. 사용자에게는 무엇이 바뀌었는지와 확인한 범위를 한국어로 짧게 알린다.

## 반복해서 낸 실수 — 반드시 피할 것

- **줄 중간에 `//` 주석을 붙이면 그 줄의 나머지 코드가 통째로 주석이 된다.** 이 프로젝트는 한 줄이 매우 길어서 여섯 번이나 같은 사고가 났다(초월이 깨진 채 커밋된 적도 있음). 주석은 **항상 별도 줄**에 쓴다. 파이썬으로 문자열을 치환할 때 특히 주의.
- 치환 전 `assert s.count(a) == 1` 로 대상이 정확히 한 곳인지 확인한다.
- 소리는 들어 볼 수 없다. 오류 없이 재생되는지만 확인되므로 사용자에게 그렇게 말한다.

## 사용자가 정한 것 (다시 묻지 말 것)

- 넓은 시야와 긴 비행을 선호. 짧은 판·가까운 카메라는 거절당했다.
- 실제 플레이는 **빠르게 튕기고 바로 환생**을 반복해 최대 구역까지 간 뒤 초월한다. 비행 시간을 늘려 주는 옵션은 가치가 없다. 설계 예시를 "끝까지 길게 나는 판"으로 잡지 말 것.
- 카드 문구는 쉽게. 값 표시는 현재 문장 + "다음 Lv" 뒤에 숫자만.
- 새 구역 골드는 기본 금액에 포함되어 보너스가 곱해지는 방식.
- 우주 가속기는 빅뱅 점화보다 비싸야 한다.
- "다른사람의 계정은 건들이지말고 불확실하면 수정하지마" — 다른 플레이어의 저장을 바꾸는 코드는 절대 넣지 않는다. 본인 저장만 다루는 버튼(골드만 비우기, 처음부터 다시)과 본인 전용 계정 저장만 있다.
- 숫자 표기는 만·억…극·항하사·아승기·나유타·불가사의·무량대수, 그 위는 "만 무량", "무량²" 식.

## 현재 구조와 수치

**구역** (`core.js` 앞부분): 이름 있는 30개(지구 10 + 실제 천문 순서의 우주 20) 뒤로 73개.
- 미지의 영역 1~50: 10개씩 다섯 공간, 공간마다 하늘 3장(1~3, 4~7, 8~10).
- 영원의 회랑 1~10(51~60), 창세의 정원 1~10(61~70): 하늘 2장씩.
- 태초의 문(71), 무한의 옥좌(72), 최후의 계산대(73): `FAR = [61.3, 62.2, 62.7]` (거리의 log10). 70까지는 구역마다 ×4.
- 하늘은 `index.html`의 `DFX`(장면 표)와 `DM`(모티프 함수), 음악은 `MUS` 안의 작곡된 9곡(`ua`~`ue`, `hall`, `garden`, `gate`, `final`)과 `sched2`.

**마지막 구역 난이도**: 전부 만렙(근력 400, 차원 엔진 150, 별의 힘 50)에 별의 힘 ×80일 때 봇 40판 중 18판이 73 도달. 사용자는 실제로 73에 도달한 기록이 있다.

**엔딩**: 73에 들어서면 `r.fin`이 서고 60초(`FIN_T`) 동안 멈추지 않는다. 끝나면 `r.finDone`, 페이지는 `state = 'ending'` → `drawEnding` → `endRun`. `s.ended` 가 엔딩 횟수.

**초월 능력** (`TPERKS`, 가격 `tCost`): 차원 엔진·금고 150, 별의 기억 75, 한계 돌파·심연 개척·별의 힘·초회전·수호 보호막 50, 견인 강화 25, 다중 광선·급속 충전 20 등.
- 50레벨 이상 능력은 10·20·30·40 구간마다 가격 상승폭이 커진다(`tStep`).
- 값이 레벨마다 더 크게 오르는 능력은 `TV`(cap, star, spin, starpow)에 식이 있다. 별의 힘은 Lv50·누적 별 2,500만 개에서 ×85.
- 초회전은 한 방향으로 2초 누른 뒤에만 빨라진다. 수호 보호막 Lv50은 어느 방향이든 완벽 착지.
- 급속 충전 Lv10부터 게이지가 100%에 닿으면 자동 발사.

**차원석** (`shardsFor`): 미지 20부터 추가분, 배율은 30:×1.3, 35:×1.5, 40:×1.8, 45:×2, 50:×3, 53:×4, 56:×5, 58:×6, 60:×7, 63:×8, 65:×9, 67:×10.

**근력 훈련 가격** (`pushCost`): Lv250까지 기존 곡선, 250~360은 레벨당 ×2.664, 360~400은 ×1.155. 차원 금고 만렙과 70 이후 반복 파밍을 전제로 맞췄다(누적 별 1억·주기 별 300만 가정).

**저장** (`index.html` 저장 부분): 슬롯 3개(`cart.save`, `cart.save.2`, `cart.save.3`, 현재 슬롯 `cart.slot`).
- 로그인해서 쓸 권한이 있는 사람은 `data/users/<id>/slotN` 에도 저장된다(본인만 접근).
- 불러올 때 판 수(`runs`)가 많은 쪽, 같으면 `rev`가 큰 쪽이 이기고 밀린 쪽은 `.bak`으로 남는다.
- 슬롯을 초기화하면 `cart.force.N` 표시로 기기 쪽이 이긴다.
- 링크로 들어온 외부 사람은 플랫폼 규칙상 쓰기가 막힐 수 있고, 그때는 기기에만 저장된다(`CLOUD.state === 'local'`).

**스킨**: 기존 6종 + 영원의 카트(`farT >= 51`), 창세의 카트(`farT >= 61`), 빛의 카트(`ended >= 1`). `farT`는 초월한 가장 깊은 구역.

## 검증되지 않은 것

- 실제 계정으로 다른 기기에서 이어받는 동작(가짜 저장소로만 테스트).
- 새 음악 9곡과 발사 효과음의 실제 소리.
- 초월을 여러 번 거듭하는 장기 진행 속도(한 주기만 시뮬레이션).
- 근력 360~400 구간의 실제 체감(가정한 별 수와 다르면 크게 달라짐).
