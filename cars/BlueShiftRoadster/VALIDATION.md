# 검증 기록

- 실제 열린 게임의 로컬 사본에서 KartFactory, Driving, KartRacingClient 및 서버 스크립트를 읽고 적용 지점을 확인했습니다.
- 기존 KartFactory의 변경 앵커 5개가 각각 정확히 한 곳임을 확인했습니다.
- Studio에서 Body와 Motion 모듈 로딩 및 설치 성공.
- 생성된 미리보기의 운전석 수: 1.
- Full 상태 60프레임 후 덮개 완전 전개 및 화염 점화 통과.
- Closed 상태 60프레임 후 덮개 닫힘과 화염 종료 통과.
- Mini 단독 상태에서 덮개 열림 비율 0, 큰 화염 0, 작은 배기구 효과 활성화 통과.
- Mini 종료 후 Closed 복귀 통과.
- 기존 로비 차량 선택에서 블루 시프트 표시 및 기본 선택 확인.

- 실제 항구 코스 경주 시작, 차량 생성 및 1인 탑승 확인.

사용자가 Esc로 화면 조작을 중단하여 플레이 중 연출의 최종 시각 검증과 장시간 주행 검증은 완료하지 못했습니다. 외형·주행감 최종 승인은 아직 받지 않았으며, 사용자의 별도 요청으로 현재 테스트 버전을 GitHub 저장 대상으로 준비했습니다.
