# 블루 시프트 — 1인승 로드스터

참고 이미지의 파란 오픈톱 스포츠카를 Roblox 기본 부품으로 재구성한 테스트용 차량입니다. 외부 유료 모델이나 업로드된 메시 없이 동작합니다.

## 기존 게임 연결
- 대상: 결승선을 통과하세요 / ReplicatedStorage.KartRacingKit
- 기존 comet(코멧)의 외형과 표시 이름을 변경합니다. 차량 선택 화면의 세 칸과 기존 성능을 유지합니다.
- 랠리·벡터, 트랙, 레이싱 규칙, 속도·가속·드리프트 판정은 변경하지 않습니다.
- 적용 전 KartFactory 사본은 ServerStorage.BlueShiftRoadster_Before_날짜 폴더에 보관됩니다.

## 연출
- 평상시: 후면 덮개 닫힘, 부스터 불꽃 꺼짐.
- 일반/아이템/출발 부스터: 약 0.56초 동안 덮개 전개, 터빈 상승, 후면 윙 상승. 전개 후반부터 큰 푸른 화염 점화.
- 순간 부스터(Mini, 기존 0.45초 판정): 덮개를 열지 않고 작은 고정 배기구의 짧은 불꽃만 표시.
- 종료: 화염이 빠르게 사라지고 약 0.72초 동안 장치가 닫힘.
- 일반 부스터와 Mini가 겹치면 진행 중인 일반 부스터 연출을 유지합니다.
- 위 시간은 시각 효과입니다. 기존 게임의 가속·부스터 지속시간은 그대로 유지합니다.

## 플레이 테스트
Studio에서 F5 → 차량 블루 시프트 선택 → 기존 방식으로 경주 시작.
W/S 전후진, A/D 조향, Shift 드리프트, Ctrl 일반 부스터.
순간 부스터는 기존 드리프트 후 재가속 판정을 그대로 사용합니다.

## 파일
- BlueShiftRoadster.rbxmx: 설치용 Roblox 패키지.
- Body.luau: 차체, 1인석, 바퀴 외형, 가동 덮개/터빈/윙과 배기구.
- Motion.luau: 프레임 단위 전개·닫힘·불꽃 애니메이션.
- Client.client.luau: 각 클라이언트의 차량 연출 실행.
- Install.luau: 기존 게임의 확인된 위치만 수정하는 설치 코드.

다른 컴퓨터에서는 Studio의 파일 → Roblox 모델 가져오기로 rbxmx 파일을 불러온 다음, 편집 모드 명령 창에서 다음을 실행합니다.

```lua
require(workspace.BlueShiftRoadster.Installer).Run()
```

같은 게임에 중복 실행하면 중단됩니다. 기존 게임 구조가 다르면 앵커 검증에서 중단됩니다.
